## The brief

Saelle Care sells a four-step routine (cleanse, tone, treat, moisturize) plus refills. Shoppers
choose by skin type and step and read the ingredients before they buy, so the store runs on typed
data, not product copy.

## How it's built

Everything that defines the store lives in the repository.

- One tokens file sets the theme, the brand book and the social images, and a contrast check
  blocks any color pair below WCAG AA.
- One command loads the catalog, size variants, ingredients, collections, pages, journal,
  policies and menus. Running it twice changes nothing.
- Skin type, key ingredients and how to use come from fields the merchant edits in the admin.
