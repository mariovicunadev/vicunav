---
title: Product pages driven by skin type and ingredients
project: saelle-care
problem: Skincare shoppers decide by skin type, ingredients and how to use a product, and none of that should be buried in a description.
decision: Skin type chips linked to collections, key ingredients from metaobjects, how-to-use bound to a metafield, and a refill template that links back to its bottle.
surfaces: [theme, data]
skills: [Metaobjects, Metafields, Theme blocks, Liquid]
quality:
  - Every block reads from fields the merchant edits in the admin
  - Refill products use their own template, set by the seed
order: 1
---
Three custom blocks (product attributes, key ingredients and refill for) read typed data, so a
merchant changes a product's skin types or ingredients in the admin and the page follows. The seed
sets each refill's template suffix and its `custom.refill_for` reference, so the refill page points
back to the bottle it tops up.
