---
title: Content as code
project: saelle-care
problem: Pages, journal articles, policies and menus are usually built by hand in the admin and can't be reviewed or rebuilt.
decision: "Seed them from JSON like the catalog: menus link by handle and only change when their structure differs; article images are composed from the packshots."
surfaces: [data]
skills: [Admin GraphQL API, Idempotency, Node.js]
quality:
  - Rerunning the seed reports menus and policies as unchanged
  - Resources without upsert use lookup, compare, then write
order: 6
---
Not every Shopify resource has an upsert mutation. For pages, articles, policies and menus the seed
looks the resource up, compares it with the source file and writes only when something changed, so
the second run is a no-op like the catalog.
