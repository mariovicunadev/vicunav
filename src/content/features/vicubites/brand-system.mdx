---
title: A brand built on the nutrition label
project: vicubites
problem: The store still looked like the default theme, while the packaging already had an identity built around nutrition data.
decision: "Turn the nutrition label into the system: palette, type, buttons, cards and one accent color per protein, all from theme settings and checked for WCAG contrast."
surfaces: [theme]
skills: [Design systems, Accessibility, WCAG 2.2, CSS, Liquid]
quality:
  - Every text pairing ≥ 4.5:1, UI and focus ring ≥ 3:1, ratios generated by script
  - Focus never hidden by sticky UI; targets ≥ 24 × 24 px
  - Reduced motion and no-JavaScript show final values
order: 3
---
Every palette, font, button, input, badge and card value comes from theme settings, so the merchant
can change them in the editor; the brand stylesheet only exposes them as custom properties.
Product cards carry a protein bar, a data row and the species icon, and the feeding calculator and
analysis bars animate only when the shopper allows motion.
