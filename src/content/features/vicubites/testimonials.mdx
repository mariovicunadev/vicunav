title: Testimonials from owners and clinics
project: vicubites
problem: Pet owners and clinics trust other buyers, and the theme had nowhere to show them.
decision: A section with a private _testimonial block for the quotes and public theme blocks for the heading area; a grid on desktop and a CSS scroll-snap carousel on mobile.
surfaces: [theme]
skills: [Theme blocks, Liquid, CSS, Accessibility, Progressive enhancement]
quality:
  - Works without JavaScript
  - Rating announced to screen readers ("Rated 5 out of 5")
order: 9
---
The section mixes two kinds of blocks: `_testimonial` is private, so it only appears inside this
section, while the heading area accepts any public theme block (text, badge). The schema declares
both with `"blocks": [{ "type": "@theme" }, { "type": "_testimonial" }]`.

On mobile the list scrolls horizontally with snap points. No carousel script is involved, so it
works before JavaScript loads and respects the shopper's own scrolling.
