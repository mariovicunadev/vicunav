---
title: Badges and benefits in any section
project: vicubites
problem: Merchants need to flag products ("Grain free", "Best seller") and list selling points in any section, and Horizon has no block for either.
decision: Two small public theme blocks that work in any section accepting @theme blocks; the badge text can come from a dynamic source and hides itself when empty.
surfaces: [theme]
skills: [Theme blocks, Liquid, Dynamic sources, Accessibility]
quality:
  - Badge text is real text; decorative icons are aria-hidden
  - Color scheme and style settings, no custom CSS per instance
order: 8
---
Both blocks follow Horizon's own conventions: `block.shopify_attributes`, CSS custom properties and a
stylesheet per block, with icons from the theme's existing icon set. A merchant connects a badge to
a product metafield or tag in the editor, so a "Grain free" badge appears only on the products
where that data is true.

The Benefit block (icon, title and short text) lays out as a row of three on desktop and stacks on
mobile when placed inside a group, without any new section.
